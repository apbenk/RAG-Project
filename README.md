# RAG Document QA System

## 📌 Description
This project is a web-based Retrieval-Augmented Generation (RAG) system that allows users to upload documents and ask questions based on the content.

## 🚀 Features
- Upload PDF documents
- Semantic search using FAISS
- Question answering with LLM
- Fast and efficient retrieval

## 🛠️ Tech Stack
- Python
- Flask
- FAISS
- NLP / Embeddings

## ▶️ How to Run
```bash
pip install -r requirements.txt
python app.py
```
